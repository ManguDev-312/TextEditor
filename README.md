# TextEditor

Text Editor is a powerful text editor with an extremely aesthetic, modern, and intuitive design. It offers unique and exceptional versatility, so much so that it can literally be run and operated even within plain text applications like Windows Notes or TextEdit on macOS.

Main Features
Quickly write and edit text with a modern and clean user interface.

Aesthetic and minimal design for a distraction-free typing experience.

Maximum versatility: lightweight and portable, it works anywhere, even within text editors like Windows Notes and macOS TextEdit.
